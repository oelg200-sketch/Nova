# NOVA Instruments

Tienda editorial de instrumentos musicales construida con HTML, CSS y JavaScript puro.

## Incluye

- Catálogo filtrable por categoría y búsqueda.
- Orden por precio.
- Favoritos y carrito de compras interactivo.
- Vista rápida de cada producto.
- Diseño responsive para móvil, tablet y escritorio.
- Formulario de suscripción con confirmación visual.
- Imágenes de producto y hero provenientes de Pexels.

La página principal se encuentra en `index.html` y todos los datos de productos se editan desde `js/main.js`.
